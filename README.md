# Trip Planner

A day-by-day trip planner with a linked hour-by-hour schedule. Runs entirely in the browser — no server, no account.

- **Plan:** add time ranges with descriptions to each day; they appear as blocks on the schedule (and edits on either side stay in sync).
- **Save / Open:** trips are saved as `.json` files. In Chrome and Edge, Save writes back to the file you opened; other browsers download a copy.
- **Draft:** your current trip is also kept in this browser, so a refresh loses nothing.
- **Shortcuts:** Ctrl/Cmd+S save, Ctrl/Cmd+Shift+S save as, Ctrl/Cmd+O open, Ctrl/Cmd+Z undo, Ctrl/Cmd+Shift+Z redo.

## Files

- `index.html` – the page structure (open this one)
- `styles.css` – the look: colors, type, layout
- `app.js` – the behavior, split into numbered sections listed at the top of the file

Keep the three files together. Hosted with GitHub Pages from `index.html` on the `main` branch.
